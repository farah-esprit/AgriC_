🔑 OBTENIR UNE CLÉ API GOOGLE VISION - ÉTAPES DÉTAILLÉES
══════════════════════════════════════════════════════

1️⃣ CRÉER UN PROJET GOOGLE CLOUD
────────────────────────────────

   1. Allez sur: https://console.cloud.google.com/
   2. Connectez-vous avec votre compte Google
   3. En haut, cliquez sur "Sélectionner un projet"
   4. Cliquez sur "NOUVEAU PROJET"
   5. Entrez le nom (ex: "AgriConnect")
   6. Cliquez "CRÉER"
   7. Attendez 30 secondes que le projet soit créé

2️⃣ ACTIVER L'API VISION
───────────────────────

   1. Allez sur: https://console.cloud.google.com/apis/library
   2. Cherchez "Vision API" dans la barre de recherche
   3. Cliquez sur le résultat "Cloud Vision API"
   4. Cliquez sur le bouton bleu "ACTIVER"
   5. Attendez quelques secondes

3️⃣ CRÉER LES IDENTIFIANTS (CLÉ API)
────────────────────────────────────

   1. Allez sur: https://console.cloud.google.com/apis/credentials
   2. Cliquez sur le bouton "+ CRÉER UNE CLÉ D'IDENTIFICATION"
   3. Sélectionnez "Clé API"
   4. Une nouvelle clé s'affiche dans une popup
   5. La clé ressemble à:
      AIzaSyDxF1g0jG2H4k8L9m0N1p2Q3r4S5t6U7v8W
      (environ 39 caractères, commence par "AIzaSy")
   6. Cliquez sur l'icône "COPIER"

4️⃣ AJOUTER LA CLÉ À VOTRE PROJET
─────────────────────────────────

   Fichier: .env

   Trouvez cette ligne:
   VISION_API_KEY=YOUR_VISION_API_KEY

   Remplacez par (avec votre vraie clé):
   VISION_API_KEY=AIzaSyDxF1g0jG2H4k8L9m0N1p2Q3r4S5t6U7v8W

5️⃣ REDÉMARRER LE SERVEUR
────────────────────────

   Fermez le serveur (Ctrl+C)
   Puis relancez:
   symfony serve

6️⃣ TESTER
─────────

   Allez sur: http://localhost:8000/culture/analyser-image

   Uploadez une image et cliquez "Analyser"

   ✅ Si ça marche → C'est bon!
   ❌ Si erreur → Vérifiez la clé

❓ PROBLÈMES COURANTS
═════════════════════

Q: "Clé API non configurée"
A: Vérifiez que:
   - VISION_API_KEY est dans le .env
   - La valeur ne commence pas par "YOUR_"
   - Pas de guillemets supplémentaires
   - Le cache a été vidé
   - Le serveur a été redémarré

Q: "Invalid API Key"
A: La clé est mal recopiée ou expirée
   - Recopier exactement depuis Google Cloud
   - Vérifier pas d'espace au début/fin

Q: "Permission Denied"
A: L'API Vision n'est pas activée
   - Aller à https://console.cloud.google.com/apis/library
   - Chercher "Vision API"
   - Cliquer "ACTIVER"
